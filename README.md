# Disease Detectives (Science Olympiad, Division C)

- `tests/` - 300 Division C Disease Detectives tests (2014-2026) from the scio.ly test archive, one readable `.txt` per test, grouped by season (`tests/2026/2026_<tournament>_<id>.txt`). `tests/INDEX.md` lists every test with question count and how many questions the archive omitted. `tests/images/` holds the figure images the tests reference. The archive provides NO answer keys.
- `resources/` - old notes (`Disease Detectives 24HS Re-redraft Notes.pdf`).
- `notes/` - `Disease_Detectives_Cheatsheet.docx` (+ `.txt` copy): two sides of one 8.5x11 sheet, Arial 4.5 pt, 0 margins, single spacing, words only. `Image_Suggestions.md` lists pictures to paste if you trade text for images.

The archive's copy of a test can be missing questions (copyright or figures it could not capture); see the "Omitted Qs" column in `tests/INDEX.md`.
