[STIMULUS] The most straightforward way to calculate the R0 for an outbreak is using the SIR model. We define:
• N to be the total population
• S to be the number of susceptible individuals, and s = S/N
• I to be the number of infected individuals, and i = I/N
• R to be the number of removed individuals, and r = R/N

To make this model work, we have to make a number of key assumptions that often are unrealistic. Firstly, we assume that the population, N, is constant and the population itself doesn't change.

[STIMULUS] We can also define the following equations:

ds/dt = −βsi  (1)
